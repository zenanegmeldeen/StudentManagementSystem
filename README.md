# Student Management System

A simple Student Management System built with C++.

## Features

- Add students
- Show students
- Search for a student
- Delete a student
- Update student information
- Calculate letter grades
- Validate age and grade
- Menu-based console interface

## Technologies

- C++
- Object-Oriented Programming (OOP)
- Arrays
- Loops
- Functions
- Conditions

## How to Run

Compile and run `main.cpp` using a C++ compiler.
